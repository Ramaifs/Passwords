Создание и управление паролями для различных платформ.

Не имеет доступа к интернету, все действия происходят локально на компьютере.

На данный момент находится в стадии Бета.

План проекта:
Сделать сайт, в котором будут синхронизироваться пароли через гугл аккаунт (данные будут храниться в Google Drive);
Редактирование паролей через сайт (поддержка браузеров);
Найти хостинг (возможно сделаю хост компом, на втором диске с линкуксом);
Выбор метод сохранения паролей:
Частное (локальное) (по умолчанию) - сохранение данных на компьютере пользователя, без подключения к интернету
Гибрид (локальное + облачное) - сохранять данные в компьютере, но попутно синхронизировать пароли с своим аккаунтом Google Drive;
Попробовать подключить к проекту двухфакторку (не факт, что получится)
